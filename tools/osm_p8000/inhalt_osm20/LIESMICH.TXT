OS/M 2.0 fuer den P8000 (8-Bit-Teil) - Systemdiskette des k1520emu
===================================================================

Betriebssystem: OS/M 2.0 (P8000, ZFT/KEAW, Version vom 15.04.1987), ein
CP/M 2.2. Diskettenformat 5: 80 Spuren, beidseitig, 16 x 256 Byte (640K);
vier Systemspuren mit dem Urlader. Start im Emulator: Diskette in
Laufwerk A: einlegen, Kaltstart, am Monitor zweimal RETURN.
Dieser Urlader prueft vor dem Start die Leitungen der Konsolschnittstelle
(tty1): das Terminal muss angeschlossen sein. Der Emulator schliesst das
eingebaute Terminal und das P8000-Terminal selbst richtig an; bei einer
Verbindung ueber Telnet oder RFC 2217 muss die Gegenstelle DTR setzen.
Die Datei README beschreibt die Diskette in der Fassung der Auslieferung.

SYSTEM
------
  SYSGEN        System auf eine andere Diskette schreiben
  SETFD         Diskettenformat der Laufwerke einstellen
  SETLP         Druckerparameter einstellen
  FORMAT        Diskette formatieren
  COPYDISK      Disketteninhalte kopieren
  ERRORS        Diskettenzugriffsfehler anzeigen
  PIP, STAT, SUBMIT, XSUB, DUMP   Standardkommandos von CP/M 2.2
