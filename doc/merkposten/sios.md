# SIOS 1526 — Merkposten

Betriebssystem der Sparkassen-/Bueroausfuehrung von A5120/A5130/K8924.  Entwurf `doc/design/43_sios1526.md`, Arbeitsunterlagen
`doc/sios/` (`README.md`, `handbuch_auszug.md`, `bedienung.md`, `tastatur_bediensicherung.md`, `befund_can_nfnd.md`, `befund_init.md`, Listings
`sysare11.prn`/`sysare09.prn`/`syl_lader.prn`), Format `doc/sios_diskettenformat.md`, Originale `tools/sios_a5120/original/` (README dort).
**Stand 2026-10-30:** SIOS 1.1 bootet bis `MONITOR ===== SIOS 1526/1.1 (M)_`, DAT/CLK/ASN/CAL/M/ET2 laufen, DiskTool liest und schreibt.
**Offen:** SIOS 0.9 (K7636, S4), SGEN (S7), Beispieldisketten `disks/a5120_sios1526/` (S8), D5/D6.
