# BS610-Rekonstruktion (EXPERIMENTELL)

`prg710_bs610_rek.hfe` ist ein **Eigenbau, kein Original**: die BS620-Diskette, in der Datei `BS620` der Tastaturteil durch den von
BS600 V02 ersetzt ist (K7609 am 8279). Im Emulator geprüft (Selbsttest, Menü, LIST, COPY), am echten PRG 710 **ungetestet**; läuft nur am Modell `prg710`. Im Paket.
Bau und Prüfung: `python3 -I tools/bs600/bau_disketten.py [--check]`; Hintergrund `doc/merkposten/bs600.md` Nr. 13/14, `doc/bs600/tastatur.md`.
